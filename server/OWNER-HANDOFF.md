# 사용자 개입을 최소화하는 서비스 준비 절차

## 진행 원칙

사용자가 개발자 콘솔 사용법을 익히거나 설정값을 복사해서 전달하는 방식 대신, 접근 가능한 로그인된 브라우저에서 담당 에이전트가 입력·등록·연결·검증을 수행한다. 접근 권한이 없으면 필요한 서비스 한 곳의 로그인만 요청한다. 실제 계정 접근 가능 여부는 아직 확인하지 않았다.

비밀번호·OTP·CAPTCHA·본인 확인·결제 정보 입력은 사용자가 직접 수행한다. 약관 동의, 실명·사업자 정보, 도메인 구매와 자동 갱신 여부는 확인 없이 추정하지 않는다. 비밀 키를 채팅이나 Git으로 전달하지 않는다. 일괄 위임을 유료 구매·외부 공개 승인으로 간주하지 않는다.

## 기본 실행 순서

1. 로컬 수집·순위·데이터 보존·복구 테스트는 계정 준비와 무관하게 진행한다.
2. Google 로그인 하나를 먼저 연결해 실제 계정으로 웹의 전 과정을 검증한다. 나머지 두 로그인도 구현 범위에 유지하며 콘솔 등록을 순차 대행한다.
3. 도메인은 `maple-exp-tracker` 계열 후보를 우선 조사한다. 아직 특정 도메인의 가용성·가격을 확인하거나 구매하지 않았다. 구매 직전 정확한 이름, 최초 비용·갱신 비용·자동 갱신 여부를 한 번에 제시해 승인받는다.
4. 공개 주소가 확정되면 DNS·HTTPS·OAuth 복귀 주소를 함께 반영하고 외부 접근을 검증한다. 개인 키 페이지는 별도 출처로 유지한다.
5. 광고는 공개 서비스가 정상 동작한 다음 연결한다. 광고 계정은 사용자의 소유이며 지급·본인 확인은 사용자가 처리한다. 심사 통과를 보장하지 않는다.

## 제가 대신 입력할 정보

| 항목 | 준비 값 또는 결정 방법 |
| --- | --- |
| 서비스 표시명 | 메이플 EXP 트래커 |
| 기존 앱 이름 | 길드원 따라가기 |
| 서비스 설명 | 한국 메이플스토리의 공식 경험치 기록을 바탕으로 대표캐릭터·길드원·즐겨찾기의 성장량을 비교하는 비공식 서비스 |
| 로컬 개발 주소 | http://127.0.0.1:3100 |
| Google 복귀 주소 | http://127.0.0.1:3100/auth/google/callback |
| Kakao 복귀 주소 | http://127.0.0.1:3100/auth/kakao/callback |
| Naver 복귀 주소 | http://127.0.0.1:3100/auth/naver/callback |
| 공개 복귀 주소 | 구매·연결 완료된 PUBLIC_ORIGIN 뒤에 같은 경로를 붙임 |
| 앱 저장소 | https://github.com/mjs5ngg/maple-guild-tracker |
| 소유자·지원 이메일 | 실제 로그인 계정 소유자에게 확인. 임의 주소 작성 금지 |

로컬 주소는 이 코드에 맞춘 후보이며 각 콘솔의 허용 규칙을 실제 입력 시 확인한다. 저장소 URL은 웹 서비스 URL을 대신하지 않는다. 사용 목적과 권한은 로그인에 필요한 최소 범위로 설정한다. 개인정보 안내·탈퇴 기능·공개 홈페이지가 필요한 단계는 먼저 구현하고 실제 주소를 등록한다.

## 사용자에게 요청할 최소 행동

- 로그인 세션이 없으면 안내한 콘솔에 로그인하고 완료했다고 알려주기. 설정 화면 입력과 키 연결은 제가 진행한다.
- 본인 확인·보안 인증이 나오면 그 단계만 직접 처리하기.
- 도메인 구매 직전에 제시한 비용과 이름 승인하기. 결제 진행은 허용된 수단과 권한 범위에서만 수행한다.
- 광고 지급 계정 정보 등 사실 확인이 필요한 부분만 직접 입력하기.

계정·결제·심사 때문에 필요한 행동을 정확한 횟수로 보장하지는 않는다. 그 외 기술적 선택은 기존에 승인된 기본안을 사용하고 불필요한 질문을 반복하지 않는다.
