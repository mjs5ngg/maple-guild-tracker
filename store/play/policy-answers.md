# Play Console 정책 설문 답변 초안

코드(2026-09-19 기준)를 확인해 작성했습니다. 기능이 바뀌면 이 문서와 설문을 함께 고쳐야 합니다.
위치: Play Console → 앱 → 정책 및 프로그램 → 앱 콘텐츠.

## 1. 개인정보처리방침
- URL: https://guildfollow.com/privacy
- 계정 삭제 안내는 같은 페이지의 "계정 삭제 방법" 항목입니다(`#account-deletion`).

## 2. 앱 액세스 권한
- "모든 기능을 특별한 액세스 권한 없이 사용할 수 있음"은 **아님**을 선택합니다.
- 이유: 조회에는 본인 명의의 NEXON Open API 서비스 키가 필요합니다.
- 심사용 안내문 예시:
  > 앱은 사용자가 발급받은 NEXON Open API 서비스 키로 동작합니다. 심사용 키: (심사 전용으로 발급한 서비스 키를 입력). 설정 → '내 서비스 키로 직접 조회'에 키를 붙여 넣고 대표캐릭터(예: 엘크라우치)를 저장하면 순위와 그래프가 표시됩니다. Google 로그인은 선택 기능입니다.
- ⚠️ 심사용 키는 사용자가 직접 발급하고 입력합니다. 저장소에 기록하지 마세요.

## 3. 광고
- **아니요, 광고가 포함되어 있지 않습니다.**
- 근거: 앱 빌드는 `WEB_MONETIZATION_ENABLED=0`으로 광고와 제휴 영역을 끕니다(`scripts/build-app-web.mjs`, `vite.web.config.ts`).

## 4. 콘텐츠 등급(IARC 설문)
- 카테고리: "참고, 뉴스 또는 교육" 또는 "기타(유틸리티, 생산성, 커뮤니케이션 등)"에서 **유틸리티**를 고릅니다.
- 폭력, 성적 콘텐츠, 욕설, 약물, 도박에 대한 답은 모두 **아니요**입니다.
- 사용자 간 상호작용이나 콘텐츠 공유: **아니요**(채팅이나 게시판 없음).
- 사용자 위치 공유: **아니요**. 디지털 상품 구매: **아니요**.
- 예상 등급: 전체이용가(3+).

## 5. 타겟층 및 콘텐츠
- 대상 연령: **13세 이상**(13~15, 16~17, 18세 이상 선택). 아동 대상 앱이 아닙니다.
- 아동의 관심을 끌 수 있는지: 아니요.

## 6. 데이터 보안(Data safety)
기본 질문:
- 사용자 데이터를 수집하거나 공유하나요? **예**(로그인을 선택한 경우 계정 식별자와 설정).
- 전송 중 암호화하나요? **예**(모든 통신 HTTPS).
- 사용자가 데이터 삭제를 요청할 수 있나요? **예**. 앱과 웹의 설정 → 계정 탈퇴, 안내 URL `https://guildfollow.com/privacy#account-deletion`.

수집 항목(모두 **수집**이며 **공유 아님**):

| 데이터 유형 | 항목 | 필수 여부 | 목적 |
|---|---|---|---|
| 개인 정보 → 사용자 ID | Google 계정 고유 식별자(openid `sub`, 이메일은 받지 않음) | 선택(로그인 시) | 계정 관리, 앱 기능(기기 간 동기화) |
| 앱 활동 → 기타 사용자 생성 콘텐츠 | 대표캐릭터명, 즐겨찾기 캐릭터명, 따라잡기 프리셋 | 선택(로그인 시) | 앱 기능 |
| 앱 활동 → 앱 상호작용 | 무작위 방문 식별자의 해시, 접속 날짜, 세션 시작 횟수(90일 보관) | 필수 | 분석(이용 현황) |
| 기기 또는 기타 ID | 위 방문 식별자는 앱이 만든 무작위 값이며 광고 ID나 기기 ID가 아닙니다 | — | 해당 없음으로 답변 |

수집하지 않는 항목(설문에서 체크하지 않음):
- 위치, 연락처, 사진, 파일, 금융 정보, 건강 정보, 이메일 주소, 광고 ID.
- NEXON 서비스 키와 경험치 기록은 기기 밖으로 나가지 않습니다. NEXON Open API로 보내는 요청은 "사용자가 요청한 제3자 서비스로의 직접 전송"이며 개발자 서버가 받지 않습니다. 따라서 수집에 포함하지 않습니다.

## 7. 금융 기능, 건강, 정부 앱, 뉴스 앱
- 모두 **해당 없음**입니다.

## 8. 권한
- `INTERNET`만 사용합니다. 민감한 권한 선언서는 필요 없습니다.

## 9. 상표와 지식재산 주의
- 앱 이름, 아이콘, 스크린샷에 NEXON이나 메이플스토리 로고를 쓰지 않습니다. 설명에는 "비공식"임을 밝힙니다(listing-ko.md 반영).
- 스크린샷에 나오는 캐릭터 이미지는 NEXON Open API가 제공합니다. 심사에서 지식재산 문제가 제기되면 NEXON Open API 이용약관의 표시 의무("Data based on NEXON Open API")를 근거로 제시합니다.
