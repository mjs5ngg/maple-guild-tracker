# 플레이 스토어 등록 문구(한국어 기본)

Play Console → 앱 → 성장 → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣습니다.

## 앱 이름 (30자 이내)
길드원 따라가기

## 간단한 설명 (80자 이내)
메이플스토리 길드원과 즐겨찾기 캐릭터의 경험치 성장을 순위·그래프·홈 위젯으로 확인하세요.

## 자세한 설명 (4000자 이내)
길드원 따라가기는 메이플스토리 캐릭터의 경험치 성장을 매일 기록해, 길드원과 친구들이 얼마나 성장했는지 한눈에 보여 주는 비공식 보조 앱입니다.

■ 주요 기능
• 대표캐릭터 현황: 현재 레벨과 경험치율, 오늘·7일 획득량, 다음 레벨업 예상일
• 길드 순위: 길드원 전체의 오늘·7일·30일 경험치 성장 순위
• 즐겨찾기 순위: 길드가 달라도 관심 있는 캐릭터를 모아 비교
• 성장 그래프: 일별 경험치율 흐름과 기간별 획득량
• 따라잡기: 목표 캐릭터를 언제 따라잡을 수 있는지 예상
• 홈 화면 위젯: 대표캐릭터, 주간 성장, 즐겨찾기 순위를 앱을 열지 않고 확인
• 기기 간 동기화(선택): Google 계정으로 로그인하면 PC 웹과 휴대폰의 대표캐릭터·즐겨찾기 설정을 함께 사용

■ 이렇게 동작합니다
• 본인 명의의 NEXON Open API 서비스 키를 입력하면, 휴대폰이 NEXON Open API에서 직접 캐릭터 정보를 조회합니다.
• 서비스 키와 경험치 기록은 휴대폰 안에만 저장되며 저희 서버로 보내지 않습니다.
• 로그인하지 않아도 모든 조회 기능을 사용할 수 있습니다.

■ 알려 드립니다
• 이 앱은 NEXON이 운영하거나 보증하지 않는 비공식 서비스입니다.
• 자정 전후의 획득량은 NEXON의 공식 일별 기록이 준비되면 다시 정렬될 수 있습니다.
• Data based on NEXON Open API
