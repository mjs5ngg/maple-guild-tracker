# 구글 플레이 스토어 정식 등록 절차

기준일은 2026-09-19입니다. 개인 개발자 계정을 새로 만드는 경우입니다.

## 준비된 것(이 폴더)
| 파일 | 용도 |
|---|---|
| `listing-ko.md` | 앱 이름, 간단한 설명, 자세한 설명, 카테고리, 연락처 |
| `policy-answers.md` | 앱 콘텐츠 설문 답변 초안(데이터 보안, 광고, 콘텐츠 등급, 타겟층, 앱 액세스) |
| `icon-512.png` | 앱 아이콘(512×512) |
| `feature-graphic-1024x500.png` | 그래픽 이미지(1024×500) |
| `screenshots/*.png` | 휴대폰 스크린샷 5장(개요, 길드 순위, 즐겨찾기, 따라잡기, 홈 위젯). 세로:가로 비율이 2:1 이하입니다. |

앱 쪽에서 반영한 것:
- targetSdk 36. 2026-08-31부터 신규 앱에 필요한 수준입니다.
- 권한은 INTERNET 하나만 씁니다.
- 로그인 세션과 서비스 키가 백업이나 기기 이전으로 복제되지 않습니다.
- Android TV 선언을 제거했습니다.
- 개인정보처리방침에 계정 삭제 방법을 추가했습니다(`https://guildfollow.com/privacy#account-deletion`). 웹 배포 후에 반영됩니다.

## 직접 하셔야 하는 일(순서대로)

### 1. 개발자 계정 만들기(약 1~3일)
- https://play.google.com/console 에서 **개인** 계정으로 가입합니다.
- 등록비는 미화 25달러이고 한 번만 냅니다.
- 신분증으로 본인 확인을 합니다. Play Console 앱으로 Android 기기 인증도 요구됩니다.
- 공개 연락 이메일을 정합니다. 스토어에 표시되니 개인 메일과 분리하는 것을 추천합니다.

### 2. 업로드 키 만들기(한 번만)
```
powershell -ExecutionPolicy Bypass -File scripts\create-upload-key.ps1
```
- 비밀번호는 직접 입력합니다.
- 키 파일은 `%USERPROFILE%\.guildfollow\upload.jks`에 생깁니다. **파일과 비밀번호를 반드시 따로 백업하세요.**

### 3. 서명된 AAB 만들기
```
powershell -ExecutionPolicy Bypass -File scripts\package-android-play.ps1
```
- 결과 파일은 `release\guildfollow-play-v{버전}.aab`입니다.
- 스토어에 새로 올릴 때마다 `src-tauri/gen/android/app/tauri.properties`의 `versionCode`를 올려야 합니다. 현재 6000이고, 이 작업은 제게 요청하시면 됩니다.

### 4. Play Console에서 앱 만들기
- 앱 이름은 `길드원 따라가기`, 기본 언어는 한국어, 유형은 앱, 가격은 무료로 합니다.
- **정책 및 프로그램 → 앱 콘텐츠**: `policy-answers.md`를 보고 각 설문에 답합니다.
- **스토어 등록정보**: `listing-ko.md` 문구와 이 폴더의 이미지를 올립니다.
- **앱 서명**: "Google에서 앱 서명 키 관리(Play 앱 서명)"를 사용합니다. 기본값입니다.

### 5. 비공개 테스트(필수, 최소 14일)
- 2023-11-13 이후 만든 개인 계정은 **테스터 12명 이상이 14일 연속 참여**해야 프로덕션 출시를 신청할 수 있습니다.
- 테스트 → 비공개 테스트 → 트랙 만들기 → 3번의 AAB를 업로드합니다.
- 테스터는 이메일 목록이나 Google 그룹으로 추가합니다. 테스터가 **참여 링크로 동의하고 앱을 설치**해야 합니다.
- 14일 동안 12명 이상이 계속 참여 상태여야 합니다. 중간에 나가면 그 사람의 날짜가 다시 시작됩니다. 여유 있게 15명 이상을 추천합니다.
- 기간 중 받은 의견을 반영해 업데이트를 1~2번 올리면, 프로덕션 신청 설문에 쓸 내용이 생깁니다.

### 6. 프로덕션 액세스 신청
- 대시보드 → "프로덕션 액세스 신청"에서 설문에 답합니다. 테스트 방법, 받은 의견, 출시 준비 상태를 적습니다.
- 검토에는 보통 며칠 걸립니다.

### 7. 정식 출시
- 프로덕션 트랙에 출시를 만들고 검토를 제출합니다. **이것이 "최종 등록"입니다.**

## 심사에서 걸릴 수 있는 점
- **서비스 키 필요**: 심사자가 쓸 수 있는 NEXON 서비스 키를 "앱 액세스"에 적어야 기능 확인이 됩니다. 심사용 키를 따로 발급하는 것을 추천합니다.
- **지식재산**: 아이콘과 이름에 메이플스토리 상표를 쓰지 않았습니다. 설명에 "비공식"과 "Data based on NEXON Open API"를 밝혔습니다. 그래도 스크린샷의 게임 캐릭터 이미지로 문의가 오면 NEXON Open API 이용약관을 근거로 답변합니다.
- **계정 삭제 URL**: 웹을 다시 배포해야 개인정보 페이지에 삭제 안내가 보입니다.
